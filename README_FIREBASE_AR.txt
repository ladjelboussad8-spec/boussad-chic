BOUSSAD CHIC - نسخة ربط Firebase

1) افتح Firebase Console > Firestore Database > Rules.
2) استبدل القواعد الحالية بمحتوى firestore.rules الموجود في هذا المجلد ثم اضغط Publish.
3) Authentication > Users: تأكد أن المستخدم الذي أنشأته يملك UID التالي:
   N0FGcJ2tIzcOu8GpQNidQFdqdGe2
4) افتح index.html عبر استضافة HTTPS (مثل Firebase Hosting). لا تعتمد على فتح الملف مباشرة file:// لأن وحدات Firebase تعمل بشكل موثوق عبر خادم ويب.
5) دخول الإدارة يتم ببريد وكلمة مرور حساب Firebase Authentication. لا توجد كلمة مرور تجريبية.

ما الذي تتم مزامنته؟
- بيانات المنتجات وأسعار وشركات التوصيل في documents/store/public.
- طلبات الزبائن تضاف إلى collection/orders.
- قراءة الطلبات وتعديل بيانات المتجر محصوران بحساب المدير المحدد في قواعد Firestore.
- يستطيع الزبون إنشاء طلب دون قراءة طلبات الآخرين.

ملاحظات مهمة قبل النشر:
- إعدادات Firebase Web SDK مضمّنة في الواجهة وهذا طبيعي لتطبيقات الويب؛ الحماية تعتمد على Authentication وقواعد Firestore.
- قواعد إنشاء الطلبات تسمح بإنشاء طلبات عامة مع تحقق أساسي فقط. قبل إطلاق تجاري واسع، أضف App Check وتحققاً أقوى من حقول الطلب ومعدلات الإرسال.
- صور المنتجات لا تزال تعتمد على حقل image الحالي؛ Firebase Storage غير مفعّل لأن مشروعك يطلب خطة Blaze له. يمكن استعمال روابط صور HTTPS حالياً.
- بعد نشر القواعد، سجّل الدخول كمدير واحفظ بيانات المنتجات/الشحن مرة واحدة لرفعها إلى Firestore.
